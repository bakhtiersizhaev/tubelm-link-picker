# Chrome Web Store upload assets

Use these files in the Chrome Web Store Developer Dashboard:

- `screenshot-01-hero.png` — required screenshot, 1280 x 800 PNG. Captured from a Playwright Chromium session with the unpacked extension loaded on a YouTube search/results page; `.tubelm-checkbox` count was 25 before capture.
- `screenshot-02-search-results.png` — additional required-format screenshot, 1280 x 800 PNG. Captured from a Playwright Chromium session with the unpacked extension loaded on a second YouTube search/results page; `.tubelm-checkbox` count was 33 before capture.
- `promo-small-440x280.png` — required small promotional tile, 440 x 280 PNG.

Do not upload generated mockups as required CWS screenshots. If you replace these screenshots, keep them square-corner, no-padding, full-bleed browser captures at 1280 x 800 or 640 x 400.
