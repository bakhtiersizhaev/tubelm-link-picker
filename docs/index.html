English: install for beginners

Install TubeLM from the Chrome Web Store for the normal one-click setup. Use the GitHub ZIP only when you want to inspect the source or load a development copy.

1. Install from Chrome Web Store

  1. Open TubeLM Link Picker on the Chrome Web Store.
  2. Click Add to Chrome.
  3. Confirm Add extension.
  4. Pin TubeLM from the puzzle-piece extensions menu.
  5. Open YouTube and start selecting videos.

2. Optional source install

  1. Open the TubeLM GitHub page.
  2. Download the source ZIP and extract it.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode, then click Load unpacked.
  5. Select the extracted folder that contains manifest.json.

3. Use on YouTube

  1. Open YouTube.
  2. Go to a channel, playlist, search results page, feed, or Shorts page.
  3. Select videos with the TubeLM checkboxes.
  4. Open TubeLM and click Copy URLs.
  5. Paste the links into NotebookLM as sources.

Troubleshooting

  • If the Chrome Web Store install button is unavailable, open the link in Chrome or another Chromium browser.
  • If Chrome cannot load it, select the folder that contains manifest.json.
  • If checkboxes are missing, reload the YouTube tab.
  • If Chrome shows a developer-mode message, that is normal only for the optional source install.

Русский: установка для новичков

Обычная установка TubeLM теперь идет через Chrome Web Store в один клик. ZIP с GitHub нужен только для проверки исходников или ручной developer-установки.

1. Установите из Chrome Web Store

  1. Откройте TubeLM Link Picker в Chrome Web Store.
  2. Нажмите Добавить в Chrome.
  3. Подтвердите установку расширения.
  4. Закрепите TubeLM через иконку пазла в панели расширений.
  5. Откройте YouTube и начинайте выбирать видео.

2. Ручная установка из исходников

  1. Откройте страницу TubeLM на GitHub.
  2. Скачайте source ZIP и распакуйте архив.
  3. Откройте Chrome и перейдите на chrome://extensions.
  4. Включите Режим разработчика, затем нажмите Загрузить распакованное.
  5. Выберите распакованную папку, внутри которой лежит manifest.json.

3. Используйте на YouTube

  1. Откройте YouTube.
  2. Перейдите на канал, плейлист, страницу поиска, ленту или Shorts.
  3. Отметьте нужные видео чекбоксами TubeLM.
  4. Откройте TubeLM и нажмите Copy URLs.
  5. Вставьте ссылки в NotebookLM как источники.

Если не работает

  • Если кнопка установки из Chrome Web Store недоступна, откройте ссылку в Chrome или другом Chromium-браузере.
  • Если Chrome не загружает расширение, выберите папку с manifest.json.
  • Если чекбоксы не появились, перезагрузите вкладку YouTube.
  • Если Chrome показывает сообщение про режим разработчика, это нормально только для ручной установки из исходников.

中文：新手安装教程

普通用户建议直接从 Chrome Web Store 一键安装 TubeLM。GitHub ZIP 只适合查看源码、测试或手动开发安装。

1. 从 Chrome Web Store 安装

  1. 打开 Chrome Web Store 上的 TubeLM Link Picker。
  2. 点击 Add to Chrome。
  3. 确认安装扩展程序。
  4. 通过拼图图标菜单把 TubeLM 固定到工具栏。
  5. 打开 YouTube，开始选择视频。

2. 可选：从源码手动安装

  1. 打开 TubeLM GitHub 页面。
  2. 下载 source ZIP 并解压。
  3. 打开 Chrome，进入 chrome://extensions。
  4. 开启 Developer mode（开发者模式），然后点击 Load unpacked。
  5. 选择包含 manifest.json 的解压文件夹。

3. 在 YouTube 上使用

  1. 打开 YouTube。
  2. 进入频道、播放列表、搜索结果页、首页推荐流或 Shorts 页面。
  3. 用 TubeLM 的复选框选择需要的视频。
  4. 打开 TubeLM，点击 Copy URLs。
  5. 把链接粘贴到 NotebookLM 作为 sources。

无法使用时

  • 如果 Chrome Web Store 安装按钮不可用，请在 Chrome 或其他 Chromium 浏览器中打开链接。
  • 如果 Chrome 无法加载扩展，请选择包含 manifest.json 的文件夹。
  • 如果 YouTube 没有显示复选框，请刷新 YouTube 标签页。
  • 如果 Chrome 显示开发者模式提示，这只对源码手动安装是正常现象。

Español: instalación para principiantes

La instalación normal de TubeLM ahora se hace en un clic desde Chrome Web Store. El ZIP de GitHub queda para revisar el código fuente, probar o cargar una copia de desarrollo.

1. Instala desde Chrome Web Store

  1. Abre TubeLM Link Picker en Chrome Web Store.
  2. Haz clic en Add to Chrome.
  3. Confirma Add extension.
  4. Fija TubeLM desde el menú de extensiones con icono de rompecabezas.
  5. Abre YouTube y empieza a seleccionar videos.

2. Instalación opcional desde código fuente

  1. Abre la página de TubeLM en GitHub.
  2. Descarga el source ZIP y descomprímelo.
  3. Abre Chrome y entra en chrome://extensions.
  4. Activa Developer mode o Modo de desarrollador, luego pulsa Load unpacked.
  5. Selecciona la carpeta extraída que contiene manifest.json.

3. Usa en YouTube

  1. Abre YouTube.
  2. Entra en un canal, playlist, resultados de búsqueda, inicio o Shorts.
  3. Selecciona videos con los checkboxes de TubeLM.
  4. Abre TubeLM y haz clic en Copy URLs.
  5. Pega los enlaces en NotebookLM como fuentes.

Si algo no funciona

  • Si el botón de Chrome Web Store no está disponible, abre el enlace en Chrome u otro navegador Chromium.
  • Si Chrome no puede cargar la extensión, selecciona la carpeta que contiene manifest.json.
  • Si no aparecen checkboxes, recarga la pestaña de YouTube.
  • Si Chrome muestra un aviso de modo desarrollador, eso es normal solo para la instalación opcional desde código fuente.
