TubeLM Link Picker - Privacy Policy

Last updated: May 2026 · Maintained by Bakhtier Sizhaev

TubeLM Link Picker ("TubeLM", "the extension") is a free, open-source Chrome extension that helps you select YouTube videos and Shorts on youtube.com and copy clean URLs to your clipboard for pasting into NotebookLM or other research tools.

This privacy policy explains how the extension handles your data. The short version: it does not collect, store, or transmit any of your data.

1. What data we collect

None. TubeLM does not collect, transmit, or sell any personal information, browsing history, identifiers, authentication tokens, financial information, health information, personal communications, location, web history, or any other category of user data defined by the Chrome Web Store Developer Program Policies.

2. How TubeLM works

  • The content script runs only on https://*.youtube.com/* pages, where it adds checkbox overlays to video tiles.
  • Your selection is held in memory inside the active YouTube tab while the page is open.
  • When you click "Copy selection", the chosen URLs are written to your local clipboard via the standard navigator.clipboard / chrome.clipboardWrite permission.
  • Nothing is sent to the extension developer or to any third-party server.

3. Permissions justification

  • activeTab - read the URL and inject the picker into the YouTube tab you are currently viewing.
  • scripting - inject the picker UI and read video metadata directly from the YouTube page DOM.
  • clipboardWrite - write the list of selected URLs into your clipboard.
  • host_permissions: https://*.youtube.com/* - the extension only operates on YouTube domains.

4. Remote code

TubeLM does not download, execute, or interpret remote code. All JavaScript is bundled inside the extension package and reviewable in the public source repository on GitHub. There is no eval(), no remote script loading, no remote configuration, and no auto-update of scripts at runtime.

5. Third-party services

TubeLM does not integrate any analytics, telemetry, error tracking, A/B testing, or advertising SDKs. It does not contact any backend service.

6. Children

TubeLM is not directed at children under 13 and does not knowingly collect data from anyone. Because no data is collected, no special handling for minors is required.

7. Open source

The complete source code is published under the MIT license at github.com/bakhtiersizhaev/tubelm-link-picker. Anyone can audit the codebase and verify the claims in this policy.

8. Changes to this policy

If TubeLM ever changes how it handles data, this page will be updated and the "Last updated" date above will change. Material changes will also be reflected in the Chrome Web Store listing.
